## 共同契约 G-01–G-12

| ID | 必须执行的行为 |
| --- | --- |
| G-01 身份与数据归属 | 每次私有读取及提交绑定本人、登录实例、单空间、恢复纪元及适用的会话/操作/候选。切账号、退出、切空间、纪元改变先隔离并清旧私有视图；旧回包不得写新视图。后台页回前台先核当前 context。平台入口使用平台权限，业务入口使用当前业务权限。 |
| G-02 初值与必填 | 下文“空”表示不替用户选择资源、角色或付费动作。“当前”来自本次已鉴权服务端上下文；直接从库进入可带入该库并显式展示。技术version_id、来源版本身份与业务版本标签分名展示；业务标签缺失写“未标注”，不从ID推断产品适用性。只读事实不得以可编辑字段伪装。必填标签与错误均可被辅助技术读取。 |
| G-03 有效配置 | 文件、页数、批量、输入及期限等读取当前生效配置并标明范围/单位；配置未知显示“限制暂不可用”并阻止相应新受理，不当作无限。新受理按当前配置，同 Key 原操作沿受理快照及原期限恢复。模型/部署实际上限由 P0 验证；不编造实测值。 |
| G-04 校验 | 提交前显示可确定的字段错误，提交后以服务端当前校验为准。错误贴近字段且有摘要，首个错误可聚焦，合法输入保留。问题/日志不静默裁剪；目标不静默删减。管理字段的有限长度、密码强度、精确序列化由 Winston/Amelia 定义服务端 schema 并向表单提供相同提示，属于常规实现细节，不得改变既定合法角色/资源/业务动作。 |
| G-05 提交与副作用 | 一个显式提交只触发该动作；提交中阻止同表单重复触发，不乐观宣布安全变更成功。列表刷新/打开详情/GET 状态不启动任务、生成、付费重交或写入。结果未知先读实际状态；未确认的写动作不自动重发。 |
| G-06 查询恢复 | 问答/对比提交前保留原 Key 和规范输入。等待、202、丢回包沿原 operation 或同 Key 恢复；浏览器超时、Abort、关页不代表业务取消/退款。failed/expired 不自动换 Key；显式“发起新请求”才能新受理。读取失败不显示成空集合。 |
| G-07 范围 | 业务范围为单空间、显式非空且不重复库；文档属于所选库。“全部有权库”先展开为本次可核对列表。任一不可用/越界整体拒绝，不回答剩余目标；无权/不存在不泄露标题、数量或存在性。空授权不出现申请审批或分享入口。 |
| G-08 保留输入 | 未提交内容只保留于同账号、同登录实例、同空间的当前内存上下文；切空间时若有未提交输入，说明会清空，给“返回编辑”和“切换并清空”。不跨账号持久保存问题、日志、答案或秘密。已受理轮次保存其规范摘要；改变范围只用于下一操作，不改原操作。 |
| G-09 危险动作 | 单文件删除/撤销凭证/取消任务用一个确认对话框，列可见对象、影响和具体按钮。删整库/解散团队/转让所有权再要求输入当前可见对象名称确认；不影响服务端最终鉴权。知情重交解析明确“可能重复外部调用及费用”，复选“我已知悉可能重复调用与费用”默认未勾，勾选且当前资格合法后才启用“确认并重新提交解析”。未提交的 Esc/关闭只放弃本次对话输入；不取消已受理后台业务。 |
| G-10 返回与焦点 | 来源关闭回原引用/矩阵格；详情返回保留当前空间合法筛选、页码与行焦点。动作移除原行时焦点落下一合法行或列表标题。对话打开移焦标题/安全操作，Tab 不逸出；关闭回触发处。轮询不反复夺焦点或播报。 |
| G-11 文案与状态 | answered/insufficient/clarify/conflict 为正常完整结果；执行/预算/依赖/校验失败单列。需处理、失权、清理失败、未知费用常驻说明；成功短提示不能替代页面最终事实。未知用“待核对/未知”，不用0、绿色或假百分比。所有展示时间及日桶为 Asia/Shanghai，原受理日不随重放跨日改变。 |
| G-12 清洗与只读证据 | Markdown/模型内容清洗渲染；引用只按服务端 citation ID 打开受控资源。前端不接任意文件路径、模型 URL、供应方临时链接；秘密不进日志/自动播报/持久缓存。状态可含安全 request/operation/task ID，详细技术错误可折叠，但不展示栈、密钥或模型思维链。 |

## IA-01 — 登录与本人账户

入口/范围：未登录访问受控内容进入登录；本人区进入账户。无自助注册、邮件/短信找回或代登录。依据：[FR-4](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:159)。

| 字段/信息 | 初值、必填及校验 | 动作与副作用 |
| --- | --- | --- |
| 账号、密码 | 空；均必填；密码支持管理器/粘贴/显隐，显隐不改变内容 | “登录”仅执行密码登录；成功先读本人 context，合法安全返回路径才可进入。登录前未完成写入/付费动作不重放 |
| 本人账号与身份 | 只读当前事实；平台与当前空间业务身份分别标注 | 不提供改他人密码或切他人身份 |
| 当前密码、新密码、确认新密码 | 空；均必填；新密码符合生效密码规则，两次一致；不对密码做 trim | “修改密码”仅改本人密码；结果确认后清三个秘密字段；会话是否失效按服务端返回处理，不据前端猜测 |
| 退出 | 无输入 | “退出登录”清私有视图，通知服务端退出；网络未知仍不留本地敏感内容，不能宣称后台任务已取消 |

冷加载不闪旧账号。身份失败统一安全文案；停用/恢复未核验按服务端可公开范围解释。登录断网保留账号，不持久保存密码；改密丢回包显示“尚未确认密码是否已修改”，先核当前登录状态，不自动再改。失败摘要获焦点；登录成功焦点到已授权页面标题。验收：AC-01、AC-18。

## IA-02 — 空间与邀请

入口/范围：顶端空间入口及本人区；仅本人个人空间、已加入团队及发给本人的站内邀请。依据：[FR-1–2](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:127)，范围：127–141。

| 字段/信息 | 初值、必填及校验 | 动作与副作用 |
| --- | --- | --- |
| 当前空间 | 成功登录后的首次无历史选择时默认个人空间；已有当前合法上下文则显示当前空间；无合法空间不能复用旧正文 | 选择另一空间遵守 G-08，确认后清旧私有状态、取新 context，并进入该空间新会话；同空间重选不新建生成 |
| 个人/团队列表 | 仅服务端当前可见项；团队名、本人角色，当前项文字标记 | 点团队不授任何额外库权 |
| 待接受邀请 | 团队、目标角色、状态；没有邀请显示“暂无待接受邀请” | “接受邀请”成功后成为成员；“已撤销/不可用”不呈接受动作。不新增拒绝/自动过期处理政策或公开加入链接 |
| 团队退出 | 普通成员可退出；所有者只见先转让说明与入口 | “退出团队”确认停止本人团队访问/凭证及职责接管，资料保留；提交后重读成员关系 |

接受结果未知先读本人邀请/成员状态；不重复受理。无团队仍有个人空间；入队但无库显示“已加入团队，尚无获授权知识库”，可返回本人空间，不新增申请按钮。失效团队上下文先隔离。验收：AC-02、AC-03、AC-18。

## IA-03 — 知识库目录

入口/范围：当前空间“知识库”。个人本人、团队所有者/维护者可创建；团队所有者全库，其他成员仅逐库范围。授权管理/整库删除只给所有者或该库负责人。依据：[FR-3](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:143)，范围：143–153。

| 字段/信息 | 初值、必填及校验 | 动作与副作用 |
| --- | --- | --- |
| 名称筛选、分页 | 空筛选、首屏第一页；初始每页20，可选20/50；筛选变化回第一页。排序默认名称升序，同名以稳定ID排序 | 只筛本次有权集合，筛选与排序不扩大权限；显示真实总数或明确当前页，不伪造全局数量 |
| 库行 | 名称、当前空间、本人动作权限、负责人职责；作用范围清晰 | 名称进入 IA-04；“在此库提问”显式带入该库新问答输入，不自动提交 |
| 创建库名称 | 空；必填、去首尾空白后非空；有效有限长度来自 schema。名称是否允许重复依服务端资源规则，不由前端猜唯一性 | “创建知识库”成功后创建者自动负责并进入库；不另要求指定负责人 |
| 库授权 | 当前合法成员及逐库访问现状；角色与访问分开，所有者固有全库范围不可单库撤销 | 保存只改该库访问；给使用者库权不提升团队角色。撤负责人该库访问时确认所有者接管且清该原负责人在该库的全部授权 |
| 删除整个库 | G-09；列停止全部库访问/引用/下载并关联清理影响 | 生效先阻断访问，后续清理；不设回收站或恢复按钮 |

角色无创建权时不显示创建。成功空集合区别“暂无知识库/暂无获授权知识库”；筛选无结果可“清除筛选”。读取失败保持错误不冒充零库；撤权后清该库内容，返回当前可见目录。管理丢回包重读状态。验收：AC-03、AC-04、AC-05、AC-18。

## IA-04 — 库内资料与文档详情

入口/范围：有权库。使用者看当前合法资料及可查询状态；维护者操作授权库全部资料，上传者身份不限制同库维护者。依据：[FR-6/8/14](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:193)。

| 字段/信息 | 初值、必填及校验 | 动作与副作用 |
| --- | --- | --- |
| 资料筛选/分页 | 空标题筛选、全部可见状态、每页20；默认最近更新在前，稳定ID作次序兜底 | 状态筛选有名称；不把处理失败/候选与生效可查性混成一个状态 |
| 资料行 | 标题、当前生效版本及可查询性、候选摘要、任务状态、更新时间 | 标题进入详情；行内“查看来源/下载原件”只按当前可读版本授权；维护动作当前授权 |
| 当前生效版本 | 无则“暂无生效版本，暂不可查询”；有则显示不可变版本标识/时间、完整或部分可用、可靠范围/失败范围 | “在此文档提问”带入当前文档范围；首次 partial 的不完整说明持续保留 |
| 候选版本 | 无则“无候选”；有则独立版本/状态/失败范围，明示“不参加当前查询” | “替换文档”进 IA-05；“查看校核/任务”进 IA-06。不完整替换不覆盖旧版，不增人工批准发布 |
| 本次任务 | 独立任务标识、阶段、截止、原因、服务端允许动作 | 与 IA-06 相同动作语义，打开详情不重试 |
| 删除文档/清理 | G-09；删除前列资料及历史来源访问影响；清理中/失败/完成另列 | 删除确认生效立即停止检索/引用/下载；清理未完成仍占容量；“重试清理”不复活文档 |
| 索引重建 | 当前 generation/profile、目标profile、维护限制、服务端允许的重建/取消动作；目标未选不提交 | 当前库维护权限显式发起同维重建；存在有效写意图则拒，不排队；重建旧索引继续读，上传/替换/重处理拒，删除仍允许。变维显示维护迁移说明，不给在线强制切换 |

完整程序校核后自动发布；内容/适用产品版本/解析参数修正形成新候选，不原地改不可变来源。详情用固定顺序“当前生效版本→候选版本→本次任务→索引重建/清理”，信息不得折叠掉当前旧版仍可用的说明。离线显示最后确认时间和“状态尚未刷新”，不推断任务失败/guard解除。验收：AC-06、AC-07、AC-08、AC-17。

## IA-05 — 导入与替换

入口/范围：当前具维护权库的“导入资料”；或某文档“替换”。依据：[导入元信息](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:193)，范围：193–203；[上传入口/恢复](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/implementation-contract.md:312)，范围：312–320。

| 字段/信息 | 初值、必填及校验 | 动作与副作用 |
| --- | --- | --- |
| 空间、库、替换对象 | 当前入口只读带入；直接进入须先显式选单空间/有维护权库。替换对象固定显示当前生效版本 | 替换提示“新版完整就绪前仍使用当前版本”；更换替换对象重新确认，不偷偷复用旧上传 |
| 文件 | 空；必填；导入可多文件、替换只对应一个文档；按当前支持格式/字节/页数/批量限制预检，最终由服务端判定加密/损坏/格式等 | 每文件预建并保留独立上传 operation ID；逐文件受理/预留/上传。一个被拒不回滚其他已受理文件 |
| 显示标题 | 选择文件后以文件名（去最后扩展名）填入，可改；必填非空 | 只作显示元信息，不以标题替代文档/版本身份 |
| 来源版本标识与业务版本标签 | 服务端候选受理后生成不可变version_id，只读；人可读资料/产品版本标签仅取真实元信息，未填显示“未标注” | 技术ID不得冒充产品v1/v2适用性；与下方可选适用产品版本/条件分开 |
| 适用型号/产品版本/条件 | 空，可选；同上下文受限文本；可选不等于未填就可无条件回答 | 内容/适用性变更走新候选，不能原地重写历史依据 |
| 处理配置 | 显示有效配置版本和解析参数；普通导入沿库合法默认；仅展示当前支持可改参数 | 参数改变属于新候选规范输入；不接受任意供应方秘密/上传签名 |
| 容量/限制 | 受理前显示当前原件容量、预留、剩余及限制；替换需新旧双份预算 | “开始导入/开始替换”逐文件受理。限制未知、guard、满额明确拒绝；不先删旧版换空间 |

提交后每文件显示“尚未受理/等待上传/上传中/原件已登记/任务已创建/过期/放弃/失败”及原期限。字节真实上传进度可显示；不把上传完成当资料就绪。断网先 GET 原候选元信息，同候选内容/长度须一致；不新增候选或重置deadline。未PUT、半传、保留失败或待核对候选可由当前维护者“放弃候选”；列旧生效版不受影响及清理余账。过期/放弃是终态，“重新上传”明确新操作。验收：AC-06、AC-07、AC-08、AC-18。

## IA-06 — 校核与任务详情

入口/范围：资料/候选/任务状态。当前维护者可看维护范围的原件/产物/错误及合法写动作；降级仍有库读权者只读本人受控任务状态，不给候选原件/他人任务/管理日志。依据：[任务权限及动作](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/implementation-contract.md:319)，范围：319–325。
