## W1 — 问答与证据近邻

| 区域 | 信息与动作 | 设计理由 |
| --- | --- | --- |
| 顶部 | 当前个人／团队空间；本人菜单 | 首先识别在哪个空间操作 |
| 左侧 | 业务导航；当前空间会话列表；新会话 | 切空间新建会话，不能混用历史 |
| 中央上方 | 本次已选知识库／文档实际清单、当前可用性；任务类型 | “全部有权库”也显示本次解析后的明确范围 |
| 中央内容 | 用户问题；完整答案卡；条件／版本／缺口；逐项引用；反馈 | 先读结论，再核验直接证据 |
| 右侧按需展开 | 选中引用的版本、页／结构路径、准确片段、原件回看 | 保持答案位置，减少在多个页面来回查找 |
| 中央底部 | 问题输入区；环境／型号等场景补充；发送；当前操作状态 | 首版非流式，等待时保留问题并说明截止；不假装逐字生成 |

SC-2 展示流程／材料／负责人缺失；SC-1 展示候选原因、检查顺序和每步引用；SC-4 展示型号、版本、数值、单位与适用条件。它们是同一答案卡的场景内容结构，不是新增权限角色。

异常：断网显示“连接中断，处理结果待确认”，提供查原操作；业务失败显示对应原因，显式新发起才能重新执行。撤权后按契约隐藏答案或来源，旧响应不得重新出现。

## W2 — 资料详情：三个对象不能合成一个状态

| 区域 | 持续显示 | 可执行动作 |
| --- | --- | --- |
| 页头 | 资料标题、所属库、本人当前维护／只读权限 | 返回资料列表 |
| 当前生效版本 | 版本、适用信息、就绪／部分可用、可查询范围 | 有权者回看原件；部分可用持续标注失败范围 |
| 候选版本 | 候选版本、处理状态、失败范围；不存在时显示“无候选” | 有权维护者按状态修订重交／重试；完整就绪才自动切换 |
| 本次任务 | 任务标识、上传起点、硬截止、最近进展、错误、外部状态 | 查状态；在合法状态取消或显式恢复；不等同候选或生效版本 |
| 清理／重建独立区 | 删除清理状态；生效索引与重建状态 | 清理失败可由有权者重试；重建保护期说明为何不能写入 |

替换候选失败时页面仍明确“当前生效版本可继续查询”，不能用整页失败遮住旧版。普通正常文档自动发布，不增加逐份人工批准。

到期任务两个分开的动作：**继续核对**只查已有任务状态／费用；**继续本地处理**另建受控任务。外部结果未知时的重新提交还需说明可能重复调用和费用，不能藏在通用“重试”按钮里。

## W3 — 多文档对比与能力核验

| 顺序 | 页面内容 |
| --- | --- |
| 1. 选对象 | 同一空间内当前可检索的 2–4 份文档；显示本次固定版本。上限采用部署有效配置 |
| 2. 写条件 | 1–6 条核验条件；显示单条／合计长度和格数限制，保留用户原顺序 |
| 3. 提交前检查 | 空、重复、超限或无权整体验证；指出可修正项，不自动删除条件或对象 |
| 4. 结果 | 条件为行、文档为列的完整矩阵；每格显示四态文字、依据／缺口和引用入口 |
| 5. 核验 | 选格后旁边显示该对象固定版本的证据；冲突同时展示互斥双方，不用A与B差异冒充单格冲突 |

四态严格沿用：**满足／明确不满足／证据不足／资料冲突**。不靠颜色识别。“证据不足”说明缺什么，不能解释为“不支持”。真正检索零候选时保留全部不足格；结构缺格或依赖失败显示整次执行失败，不能给半张成功表。

没有为本轮增加 CSV、PDF 或其他比较结果导出入口；查询范围、生成与引用语义仍由上游契约决定。

## W4 — 来源校核与复杂手册回看

| 区域 | 内容 |
| --- | --- |
| 页头 | 文档和不可变版本；当前查看的是生效版／候选／历史核验版本 |
| 左侧定位 | 可靠 PDF 物理页，或非 PDF 实际章节／段落结构；定位失败明确说明 |
| 主区 A | 明确标“原件”的 PDF 页或受控原件入口；可信 bbox 才高亮 |
| 主区 B | 明确标“提取内容”的准确片段、表格／图及失败范围；数值单位条件不折叠丢失 |
| 旁注 | 无可信区域时显示“可定位到页，无区域高亮”；非 PDF 不伪造物理页 |
| 维护动作 | 修订原件或合法元信息／解析参数，形成新候选；不原地编辑历史 |

这一能力从 S2 的最小校核开始，S5 增强表格、扫描与真正图意。首稿没有推迟基础回看，也没有加入通用 OCR 编辑器。
