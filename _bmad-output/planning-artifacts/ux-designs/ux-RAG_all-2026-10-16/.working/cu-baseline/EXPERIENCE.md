# RAG_all — EXPERIENCE

首轮完整交互设计稿，供讨论和后续设计收敛；尚未得到用户对具体布局与交互提案的逐项确认。未编码、未制作页面、未运行产品验收。

本文用 **[上游已定]** 标产品及实施契约，用 **[Sally设计提案]** 标本轮页面组织、呈现、操作和无障碍细化；未单独标注的设计规则均属于后者。用户已允许参考 RAG UI，且暂无既定品牌视觉偏好，不等于已选择本稿布局。

## Information Architecture

**[Sally设计提案]** 应用框架左侧为稳定导航，顶端持续显示当前空间，中央完成当前任务，来源按需在右侧展开；业务导航为“问答”“对比”“知识库”。本人区放“空间与邀请”“凭证与用量”“修改密码”；团队所有者可见“团队管理”，平台管理员另有“平台管理”。平台入口不进入业务资料视图。当前身份没有某动作时不呈现该动作入口；深链接和回包仍须由服务端鉴权。

| 页面／表面 ID | 从哪里到达 | 要完成的事及信息层次 | 角色与流程闭合 |
| --- | --- | --- | --- |
| IA-01 登录与本人账户 | 未登录入口；本人区 | 登录只用账号密码；账户页改本人密码与退出。没有自助注册或未获授权的找回渠道 | 有效账号；Flow 7 |
| IA-02 空间与邀请 | 顶端空间入口；本人区 | 分个人／已加入团队／待接受邀请；邀请显示团队、目标角色和当前状态。切空间前说明将进入新会话 | 本人；Flow 6、7 |
| IA-03 知识库目录 | 知识库 | 仅列当前空间有权库；名称、本人动作权限、负责人（在可读范围内）。创建入口仅在本人或团队所有者／维护者具备权限时出现 | 当前范围；Flow 5、7 |
| IA-04 库内资料与文档详情 | 库目录；问答范围中的资料入口 | 资料表格先展示可查询性与生效版本；详情固定“当前生效版本／候选版本／本次任务”三区，另列索引重建，不用一个状态吞并各对象 | 读者可读受控资料；维护动作按范围；Flow 5 |
| IA-05 导入与替换 | 库内导入；文档替换 | 当前库、文件、版本和可选型号／条件；提交前看有效限制与原件容量；逐文件显示受理与上传结果。替换明确旧版仍生效 | 当前维护权；Flow 5 |
| IA-06 校核与任务详情 | 文档详情／处理状态 | 原件和提取／结构内容对照，位置／失败范围可跳转；任务原因、截止、当前可用动作。检查不等于人工发布审批 | 当前维护者可管；仍有读权的降级提交者仅看本人状态；Flow 5 |
| IA-07 问答、检索与会话历史 | 问答；库内“在此库提问” | 当前范围→场景输入→完整答案／正常不足／澄清／冲突→引用和反馈；同空间会话列表用于历史回看。纯检索为明确的独立动作 | 当前有权范围；Flow 1、2、4、7 |
| IA-08 多文档对比与能力核验 | 对比；授权资料选择后进入 | 对象及版本→核验条件→完整四态矩阵→逐格理由／证据。与普通问答共用范围和操作恢复语义 | 当前有权范围；Flow 3 |
| IA-09 来源与历史引用 | 答案、对比格、历史或校核中的引用 | 先见文档与不可变版本，再见实际页／结构位置和准确片段；可核验原件。返回时保留来源格或结论的位置 | 每次当前鉴权；Flow 1–5、7 |
| IA-10 程序凭证与用量 | 本人区；查询限额提示 | 本人凭证元信息／创建／撤销；原件容量、产品问答计次、可见真实调用／费用分区。仅展现本人或当前管理权限允许的统计 | 凭证本人；团队所有者可撤团队凭证；Flow 8 |
| IA-11 团队管理 | 当前团队的所有者入口 | 成员与角色、已有账号邀请、库授权／负责人、所有权转让、退出／解散；职责与资料范围不混同 | 所有者；负责库授权也可从对应库进入；Flow 6 |
| IA-12 平台管理 | 独立平台入口 | 账号／团队初始所有者、模型接入／默认配置、存储／配额、任务依赖运行与审计元数据；重建／恢复仅显示授权范围内受控状态与影响说明，不由平台身份授予任意库重建权 | 平台身份不读正文；Flow 9 |

布局对应[关键界面文字线框](/E:/aaa-project/rag/_bmad-output/planning-artifacts/ux-designs/ux-RAG_all-2026-10-16/wireframes/key-surfaces.md)：W1 对应 IA-07 问答与证据近邻，W2 对应 IA-04 三类对象，W3 对应 IA-08 完整对比矩阵，W4 对应 IA-06／09 来源校核。其他页面目前由本文表格承载，未完成逐页视觉取舍。

“当前库”“当前文档”始终可由范围选择器和页面标题核对。直接进入来源或任务的链接先核上下文，再取正文；失败时保留安全的返回入口，不回显未知目标标题或部分结果。[上游目标安全边界](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/implementation-contract.md:16)，范围：16–20。

## Voice and Tone

**[Sally设计提案]** 面向做事的人，用短句说明“现在怎样、影响什么、可以做什么”。说明不确定性时保留条件与缺口；不把候选原因写成诊断结论。品牌语气见 DESIGN，这里只约束操作文案。

| 情境 | 建议文案 | 不能表达成 |
| --- | --- | --- |
| 替换处理中 | “新版处理中。当前仍使用 v1。” | “文档不可用”或只显示“处理中” |
| 首次部分可用 | “部分可用。未完成范围：{可靠范围}。答案仅使用已校核内容。” | “导入成功” |
| 查询不足 | “现有资料未提供审计能力的依据。” | “不支持审计” |
| 候选排障原因 | “这可能与连接配置有关；请先核对以下条件。” | “已经找到根因／修复成功” |
| 正常澄清 | “请补充产品版本和部署环境。” | “生成失败，请重试” |
| 外部结果未知 | “解析结果待核对。先查询原任务；重新提交可能产生额外调用与费用。” | “失败，自动重试中” |
| 丢回包 | “尚未确认本次结果。查看原操作状态，不会重新生成。” | “网络超时，已重新提问” |
| 终态失败 | “本次未完成：{安全原因}。新请求将按当前限制重新受理。” | 把失败改成“资料不足” |
| 来源不可用 | “来源位置不可用，暂不能核验这条引用。” | 静默打开文件首页或猜测页码 |
| 不可用目标 | “所选资源不可用，请重新选择范围。” | 暴露无权目标名称、数量或是否存在 |
| 原件容量 | “原件容量包含保留版本和清理中的原件；清理完成后才释放。” | “服务器磁盘已用” |
| 未知费用 | “费用待核对；已知调用：{已知事实}。” | “¥0／免费” |

系统性错误以可读原因加请求／任务标识辅助定位。具体错误码可折叠在同一状态反馈中，不把内部栈、密钥、正文日志或模型思维链作为业务 UI 内容。[错误与成本语义](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/implementation-contract.md:350)，范围：350–372。

## Component Patterns

以下十六个名称与 DESIGN 保持一致；均为 **[Sally设计提案]** 的组件组合，Element Plus 默认行为中未列出的部分继续继承。业务可执行范围仍服从上游。

答案卡／问题输入区／来源查看器的组合见[文字线框 W1 与 W4](/E:/aaa-project/rag/_bmad-output/planning-artifacts/ux-designs/ux-RAG_all-2026-10-16/wireframes/key-surfaces.md)，处理状态条／资料表格见 W2，对比矩阵见 W3；线框说明信息摆放，以下规则说明动作与状态。

| 组件 | 出现位置 | 行为契约 |
| --- | --- | --- |
| 应用框架 | IA-01–12 | 当前空间／身份持续可辨；导航不替用户授权。切空间、退出、换账号及确认恢复纪元变化时先隔离旧私有视图，再加载当前上下文；未授权内容不以缓存填充 |
| 范围选择器 | IA-02、03、07、08、10 | 单空间显式库清单，可进一步选文档；“全部有权库”提交前展开为本次实际列表，给出可见摘要。目标不可用则整请求失败，禁止偷偷去掉；凭证范围从本人当前权限构造 |
| 资料表格 | IA-03、04 | 表头说明版本和可查询状态；行内动作可键盘聚焦且按当前权限呈现。使用明确分页与筛选条件；选中项显式列出，不假设跨页全选。无整库导出／回收站入口 |
| 导入表单 | IA-05 | 提交前读取当前有效格式／大小／页数／数量和容量限制，逐文件显示字段错误与受理结果；表单自身校验不能替代服务端。替换保留旧版说明，网络重传沿原上传，不私建候选 |
| 处理状态条 | IA-04–06、12 | 分开生效／候选／任务／清理／重建，显示真实阶段、时间、截止与失败范围；没有实际百分比就不绘制百分比。只给当前状态允许的动作；就绪观测不等于本地发布 |
| 来源查看器 | IA-06、09 | 原件与提取内容标明身份；PDF可靠区域高亮，否则可靠页＋片段并写“无区域高亮”；非PDF用实际结构路径，不编页。打开、翻页、取图／下载均鉴权；返回保留来源上下文 |
| 问题输入区 | IA-07 | 场景选择沿用 SC-1／2／4 原名；按场景展开版本／环境／日志或型号／故障码／条件。保留完整输入，不为预算静默删减。纯检索和提交问答用不同动词并说明计次差异 |
| 答案卡 | IA-07、历史 | 完整校验成功后一次展示 answered／insufficient／clarify／conflict。结论、适用条件、步骤／参数与事实引用同处可核验；历史和成功重放标原时间／版本；失权时整体隐藏受影响回答 |
| 对比矩阵 | IA-08 | 固定输入对象与条件顺序，逐格恰一次且显示四态文字、理由和证据入口；状态不能仅以色区分。格子缺失、截断或非法引用整答失败，不展示貌似完整的部分矩阵 |
| 反馈条 | IA-07、08 | 针对当前答案标记错误、缺失依据或引用问题并显示提交结果；提交失败可明确重试原反馈。归属与当前答案绑定，普通账号看不到他人反馈或全局日志 |
| 凭证面板 | IA-10、团队授权范围 | 创建时明确空间／库／只读动作／到期；明文仅创建成功时出现一次，显式复制后仍不能再次取回。结果丢失不自动新建密钥；先读元信息，可撤销后由本人明确重建 |
| 用量面板 | IA-10、12、限额反馈 | 分开原件容量、产品次数、外部调用及费用；展示统计范围、上海日期／时区、预留／已结算或未知状态。费用未知不填零；失败与重试不从真实成本中消失 |
| 管理表单 | IA-03、11、12 | 明示操作者当前角色、作用范围和影响；授权与团队角色分栏判断。提交按服务端当前事实落地，不对撤权、转让、删资料做未经确认的乐观成功提示 |
| 确认对话框 | 删除／解散／转让／撤销及可能重复付费重交 | 显示对象、影响及当前可见事实，按钮写具体动作；一个任务只打开一层。没有知情上下文时不自动聚焦危险动作；关闭对话不解释为取消已受理后台任务 |
| 状态反馈 | 全页面 | 错误靠近触发位置并有安全恢复动作；需处理／失权／超时信息持续可见，不只用短暂消息。loading只表示当前读取，不掩盖真实后台状态；状态改变适度播报，不每次轮询报读 |
| 登录表单 | IA-01 | 账号和密码有真实标签，支持密码管理器与粘贴，提交中阻止重复触发；失败不泄露账号额外信息。登录成功先取本人上下文再打开受控页面；不自动重放登录前的写入或付费动作 |

## State Patterns

### 每页覆盖

**[Sally设计提案]** 表中“错误”指读取或动作的真实错误；空态只用于已成功确认的空集合。所有可操作控件具有焦点、禁用、提交中和错误关联状态；按钮禁用时在邻近文字说明原因，不把说明藏在鼠标悬停里。

| IA 页面 | 冷加载／空态 | 错误／权限变化 | 离线／恢复与焦点 |
| --- | --- | --- | --- |
| IA-01 登录与账户 | 未知身份只显示登录表单，不先显示旧账号；提交等待可辨 | 凭证无效、停用或恢复身份未核验给安全说明；改密失败保留当前表单但不报成功 | 断网不宣称密码已改；恢复后先核当前会话。失败摘要获焦点，定位具体字段 |
| IA-02 空间与邀请 | 读取上下文前不显示旧空间；无邀请写“暂无待接受邀请”，无团队仍保留个人空间 | 邀请已撤销／过期不接受；团队失效不残留资料。入队但无库授权写明确空态，不新增申请审批入口 | 接受／切换丢回包先重取当前成员／上下文，不自动再次提交。进入后焦点落空间标题 |
| IA-03 库目录 | 确认读取后才区分“暂无知识库”和“暂无获授权知识库”；只有有权创建者看到创建动作 | 读取失败不显示为零库；被撤库权移除资料且说明当前范围已更新，不泄露其他库 | 离线不发创建／删除；恢复先重核范围。筛选空结果可清筛选，焦点保留筛选处 |
| IA-04 资料与详情 | 空表给当前角色可执行的导入或返回动作；无候选明确“无候选” | 候选失败不盖住旧版可查；清理失败和来源删除分开；失权清正文。重建拒写明确原因 | 断网显示“状态尚未刷新”，不判断任务失败；恢复取当前版本／任务。返回列表保留原行焦点 |
| IA-05 导入与替换 | 空表单先显示配置读取；限制未知时不把文件当作可无限受理 | 字段／文件／容量／重建guard错误分别定位；提交前维护权已失效则停止写入，不新建候选 | 上传未确认时查原上传元信息；保持原期限，不能断网即新上传。过期／放弃须明确新上传 |
| IA-06 校核与任务 | 原件、提取、范围各自读取；没有可靠位置明确缺失，不画假预览 | 程序校核失败给范围与原因；维护者降级仅留合法本人状态读；定位坏不跳默认页 | 原件取回失败可重读；后台任务状态未知与离线分开。跳失败页时聚焦对应位置说明 |
| IA-07 问答与历史 | 新会话显示范围和场景输入；没有历史不伪造例答；历史读取不闪现旧正文 | 正常不足／澄清／冲突是结果；依赖、校验、预算失败是业务失败。失权隐藏整个受影响回答；忙／父轮次变化不混写历史 | 受理状态未知只恢复原操作；重新连线先核上下文。返回结果适度播报，焦点由用户决定，不强跳答案末尾 |
| IA-08 对比 | 未选对象／条件给明确输入；有效空候选仍回完整全格不足 | 空／重复／越限／越权整体拒；缺格、截断、非法引用整答失败，保留合法输入供本人明确新操作 | 不因断网再发一张矩阵；读原状态／结果。键盘按表头、条件、对象、格证据进入 |
| IA-09 来源与引用 | 先核版本定位，再取受控资源；无区域但可靠页走页预览 | 已知历史的安全删除提示与未知目标统一不可用边界由服务端决定；定位缺资产明确失败，当前失权不显示缓存片段 | 离线不保证原件可用；恢复重新授权取资源。关闭后回原引用或格子，不丢核验位置 |
| IA-10 凭证与用量 | 无凭证明确空态；统计未读不能显示零次／零费用 | 创建／撤销失败不报成功；失去范围时重核创建选项及可见元信息。问答次数、容量与并发达限分别解释 | 创建回包丢失不自动新建；用量标最后确认时间与未知。密钥复制结果仅播报状态，不朗读秘密 |
| IA-11 团队管理 | 无邀请与无普通成员可明确显示；有效所有者一直可辨 | 角色／权限变化重取；所有者未交接不能退出／停用。撤权对象列表不靠旧缓存提交 | 离线禁发管理写入；丢回包先核实际成员／授权状态。确认关闭回触发动作；动作生效后焦点到结果说明 |
| IA-12 平台管理 | 配置／运行状态分别读，不用空值表示已接通 | 接入未验证、存储压力、索引不兼容、恢复隔离各有可识别说明。只对有权限者显示恢复范围／配额核对细节 | 不在线自动改配置或解除guard；恢复后按当前上下文读元数据。平台身份不加载业务正文作预览 |

### 文档与任务：五条独立状态线

**[上游已定]** 状态对象和恢复语义见[上传生命周期](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/implementation-contract.md:75)，范围：75–83；[任务权属与继续核对](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/implementation-contract.md:115)，范围：115–133；[现行 UI 状态表](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/mary-m2/ui-contract.md:23)，范围：23–36。下面是 **[Sally设计提案]** 的呈现与动作命名，不改变服务端状态。

| 状态线 | 页面需要明确的事实 | 当前合法操作与停止点 |
| --- | --- | --- |
| 上传 | 等待上传／上传中／原件已登记；开始、硬截止、进展超时；过期／已放弃为原操作终态 | 同一上传恢复遵守原Key和期限；内容冲突不覆盖。到期或放弃后“重新上传”是新受理，不能把原操作复活 |
| 生效／候选 | 无生效版时写暂不可查询；已有生效版时始终显示版本；候选独立排队／处理／失败／完整就绪 | 普通完整资料程序校核通过自动发布；首次部分可用仅发布可靠范围并提示不完整；不完整替换保留候选，不盖旧版，不加逐份“批准发布”按钮 |
| 本次任务 | 阶段、已知失败范围、硬截止、原任务关联；提交者失去维护权与库任务是否继续是两件事 | 受理后的库任务归库继续；当前维护者管理。读者仅按本人及当前范围读状态，不出现维护写动作 |
| 外部未知 | “待核对”／“需处理”；原任务标识、最后可靠观测、有限核对期限、费用已知或待核对 | “查询原任务”只查原关联；到期后“继续核对原任务”创建独立有界只读核对，不续旧job、不下载发布；“继续处理”是新的本地处理操作，重过资格／预算／期限；“重新提交解析”明确可能重复外部调用与费用，须维护者知情显式执行，保留原关联 |
| 清理／重建 | 删除已阻断访问与清理中／失败／完成分别列；重建显示旧活动索引、目标配置和当前写入限制 | 清理未完成仍占原件容量；重试清理不恢复资料。重建期间旧索引继续读、删除仍允许；上传／替换／重处理拒绝且不隐形排队，guard由服务端状态解除，不由倒计时猜测 |

**[上游已定]** 云端 ready 只是外部观测；没有经过本地新操作资格与完整校核不能显示资料就绪。旧候选迟到不盖新候选，删除不被迟到结果复活。维护者知情重交也不代表原上游请求已取消。[继续处理边界](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/implementation-contract.md:127)，范围：127–133；[版本与删除要求](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:217)，范围：217–223。

### 问答／对比操作与错误恢复

**[上游已定]** 尚未受理、已受理等待、正常结果、业务失败、成功但当前无权重读必须分开；浏览器等待结束不能推断失败或自动付费重试。[前端恢复条款](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/implementation-contract.md:395)，范围：395–401。

| 当前事实 | [Sally设计提案] 页面与动作 | 配额／成本语义 |
| --- | --- | --- |
| 尚未受理 | 输入仍可编辑；修正错误后由本人提交。并发忙提示“暂未受理”，不画后台排队进度 | 没有本操作问答结算；不能据此推断所有已发生外部成本为零 |
| 已受理／执行中／网络未知 | 冻结本轮规范输入摘要；“查看本次状态”读原操作，同Key重传不新增一轮；不能换Key自动再发 | 保留原逻辑操作；原截止内恢复，不另扣一次 |
| 正常 answered／insufficient／clarify／conflict | 完整答案或完整矩阵一次显示；不足说明缺口，澄清给需要的条件，冲突并列证据 | 合规结果计一次；真实零候选不足也计一次，纯检索不扣问答 |
| succeeded 但回包丢失 | 当前重新授权后显示原结果，标原完成时间／版本及“已恢复本次结果” | 不重新检索／生成／计次 |
| failed／failed_unknown | 显示原失败和已知／未知成本；若服务端允许，提供“发起新请求”，点击前明确是新操作 | 原业务预留按契约释放；实际调用和未知费用保留，新操作可能另计／另花费 |
| 过期／纪元变化 | 原操作不再执行，显示旧操作终态；不自动变新Key或恢复纪元提交 | 只有本人显式新操作才重新受理；不静默重复扣费 |
| 成功但失去当前来源权限 | 隐藏受影响答案或矩阵，显示安全原因；不把缓存答案作为降级兜底 | 成功事实不因读回失败变新生成；不提供原敏感结果 |

恢复动作严格按服务端 `none`／`same_key_or_status`／`new_operation`／`manual_reconcile`，不把“允许新操作”解释为自动付费授权。预算不足、证据被预算裁空、模型预算未证、截断、校验、依赖失败分别解释；用户可主动缩小输入后新提交，但 UI 不擅自删日志、条件或矩阵格。真正检索成功且零候选才能呈现正常不足。[最小错误字典](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/implementation-contract.md:350)，范围：350–372。

## Interaction Primitives

**[Sally设计提案]**

- 鼠标、触摸与键盘完成同一组合法动作；主要操作有固定可见按钮，不能仅在悬停中出现。Enter 在单行表单按标准提交；多行问题／日志中 Enter 保留换行，显式“提交问答／检索／开始对比”执行，避免误付费触发。
- Esc 关闭当前尚未提交的确认对话框或来源查看器，不能隐含撤销后台任务。关闭后焦点回触发处；已移除触发处时回相邻可操作标题。一次只叠一层确认对话框。
- 范围变更在提交前可编辑；本轮已受理后摘要固定，不把新选择覆盖到执行中操作。切空间需新会话并隔离旧数据；有未提交内容时说明会被清空，用户可返回原页处理；不把业务正文保存在跨账号的浏览器持久草稿中。
- 普通问答仅一次提交；忙轮次禁发本会话下一次，显示当前未终结操作。旧页面父轮次冲突时重新取会话，用户核对后明确再提交，不自动把旧问题追加到新历史。
- 引用操作贴近对应事实／步骤／格；在宽屏来源查看器与原结果并置，窄屏进入同一来源查看器的完整页面。原答案的展开、滚动和格子位置可返回恢复，但须在当前授权仍有效时恢复正文。
- 对比条件显式新增／移除／编辑，顺序可由明确的上移／下移操作调整；不要求拖拽。使用有效配置显示数量与码点限制；越限标字段，不静默合并相似条件。文档版本在受理时固定，不随列表刷新偷换。
- 提交后的反馈、邀请、配置等动作失败就显示失败；安全变更不乐观宣布成功。删除／转让／重交解析等影响先在确认对话框写清，再发动作；确认对话不替代服务端权限复核。

**[上游已定]** 退出、换账号、切空间或确认恢复纪元变化时清私有缓存并变更本地上下文代次；旧请求即使 Abort 失败，回包也不能写新账号／空间。后台标签页回前台先核本人 context／epoch 与当前授权，再读私有内容，不自动重放旧写操作。[响应归属](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/implementation-contract.md:397)，范围：397–401。

## Accessibility Floor

**[Sally设计提案]** 这些是设计和后续实现验证目标，当前未测试、未声称合规。

- 所有输入有可读标签及必要说明；问题、版本、日志、条件、期限与密钥动作不能只依赖占位文案。错误摘要关联出错字段，提交失败可从摘要聚焦到字段；不能清掉无误的同一上下文输入。
- 全流程可只用键盘完成，焦点顺序与阅读顺序一致；焦点使用 `{colors.focus}`，不能被固定导航遮挡。状态提示不随轮询夺焦点；来源打开时说明文档、版本与位置，关闭后返回原证据位置。
- 对比矩阵保留对象列头与条件行头的关联，格子可朗读“对象／版本／条件／状态／理由／证据数量”；满足、明确不满足、证据不足、资料冲突同时有文字与视觉差别。横向滚动区域有名称及键盘入口，不用只有颜色的图例。
- 处理状态、已恢复结果、反馈成功等关键变更通过适度状态播报传达；每次轮询不重复宣布“处理中”。失权隐藏优先清除内容再给安全说明；密钥、密码不加入自动播报。
- 表格、PDF和图意均提供可读的文本上下文。图示问题的答案保留必要图意说明、图号、条件和来源，不以一张图片替代语义答案；没有可靠文字或定位时如实给缺口。
- 放大文字和浏览器缩放后主操作、字段错误、条件／单位与来源仍可达；长表格允许区域滚动，不缩小字号塞屏。触摸目标有足够间距；复杂动作不要求精细拖拽或悬停。
- 遵从减少动效偏好；不使用必须等待动画结束才能操作的反馈。正文／背景、边界和焦点的视觉对比目标由 DESIGN 定义并在实现后核验。

## Key Flows

前四条沿用 PRD 的原场景名和具名主角，人物不是真实访谈记录；来源为 [UJ-1–4](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:62)，范围：62–67。每条顺序和页面组织均为 **[Sally设计提案]**；事实与验收不变。后五条是为闭合支持页面而命名的设计走查人物，不增加产品角色或需求。

### Flow 1 — UJ-1 / SC-1：技术支持与故障排查（技术支持小林）

1. 小林在 IA-02 确认团队空间，在 IA-07 的范围选择器勾选有权知识库。
2. 选择“技术支持与故障排查”，输入 v2 升级后连接超时的问题，补版本、环境和日志；提交前看范围摘要与当次输入。
3. 提交后本会话显示原操作等待及可见截止；不显示未校验草稿，也不排入下一生成轮次。
4. 答案卡先列适用条件，再列候选原因及检查顺序；小林逐步打开 IA-09 对应版本引用。
5. **高潮：** 小林能把第一项检查与 v2 的适用条件、日志现象和原文证据对上，知道下一步如何人工核查，同时知道系统尚未确认根因、没有执行命令。
6. 若依据仍有缺口，小林在同空间追问补条件；反馈条可标记缺失依据或引用问题。

失败分支：缺必要版本／环境→正常澄清，补齐后本人发下一操作；版本不匹配→明确限制而非推荐无条件执行；依赖／预算／截断失败→整答失败且按模式恢复原状态，不伪装不足；丢回包→读原操作成功结果；输出前撤权→不交付受影响答案。对应 [FR-10](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:241)，范围：241–245。

### Flow 2 — UJ-2 / SC-2：企业内部知识查询（新员工小周）

1. 小周登录后确认已加入团队并有制度库授权；只入队尚无库时留在安全空态，不能直接查询团队所有资料。
2. 在 IA-07 选择“企业内部知识查询”和制度库，询问出差审批人、流程及所需材料。
3. 得到完整答案，先看适用条件及制度版本，再看流程、材料和有据负责人。
4. **高潮：** 小周打开流程与材料的原文引用，确认本次出差条件适用，能按有据步骤准备材料。
5. 同空间追问条件细节；之后从会话历史回看时重新授权，并可提交答案反馈。

失败分支：资料未写负责人→明确缺失，不生成人名；两份制度同条件冲突→并列版本与双方证据，不裁定哪份更有效；纯检索无结果→显示检索空态、不扣问答；问答真实零候选→正常不足且计一次；历史依赖失权→整体隐藏受影响回答。对应 [FR-11](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:247)，范围：247–251。

### Flow 3 — UJ-3 / SC-3：多文档对比与能力核验（售前小陈）

1. 小陈进入 IA-08，确认同一空间，在当前授权文档中选择产品 A 与 B，并看各自固定文档版本。
2. 录入离线部署、审计、批量导入条件，看到有效数量／码点上限；按需要编辑条件顺序，不把未选条件自动加入。
3. 提交前看对象×条件的完整范围；受理后保留原输入顺序与执行版本，等待一次完整返回。
4. 对比矩阵逐格显示满足／明确不满足／证据不足／资料冲突，以及简明理由和证据入口。
5. **高潮：** 小陈发现同一条件在 A 有直接依据、B 缺依据，能够分别解释“满足”和“证据不足”，并从具体格打开来源；不会把 B 的缺失写成“不支持”。
6. 如需版本差异比较，选择分别导入并标明版本的不同文档；历史替换版本不出现在新检索对象选择中。

失败分支：空、重复、超限或任一目标无权→整请求拒绝，不默删对象／条件；真实零候选→仍返回完整全格不足；缺格／截断／非法引用→整答失败；同格冲突需要该固定版本内双方证据，A/B差异不误标同格冲突；丢回包恢复原矩阵不重复扣次。对应 [FR-12](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:253)，范围：253–261。

### Flow 4 — UJ-4 / SC-4：复杂产品手册问答（实施工程师小赵）

1. 小赵选择手册库和“复杂产品手册问答”，输入型号 M2、E17 故障、部件位置及参数限制问题，补已知版本和条件。
2. 提交后等待完整答案；答案卡将故障说明、人工检查步骤、部件位置、参数／单位及适用限制分组，不拼接不兼容型号数据。
3. 从参数打开规则表格与简单跨页表定位，从部件打开图号／图意说明及原页，从扫描事实打开对应物理页。
4. **高潮：** 小赵在同一套有据答案里对齐型号、数值、单位、表头条件和部件位置，知道哪些步骤与参数适用于 M2，而不是只看到一张图片。
5. 若发现解析问题，用反馈条标“引用问题／错误”，由有权维护者按 Flow 5 校核并形成新候选。

失败分支：型号不明、单位缺失或解析不足→澄清／限定结论；PDF 无可信区域但有可靠页→页预览＋准确片段并标无区域高亮；非PDF→实际结构位置而非假页码；位置／hash／资源失效→明确无法核验，不跳猜测页。纯文本答对不宣称整个 SC-4 已验收。对应 [FR-13](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:263)，范围：263–267；[来源校核](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:207)，范围：207–213。

### Flow 5 — 资料导入、校核、替换与删除（知识维护者阿宁）

1. 阿宁从 IA-03 打开负责库或其他获授权维护库；新建库后自动负责，其他库的维护权不额外给授权管理权。
2. 在 IA-05 看实际格式／页数／批量限制和原件容量，提交文件、版本及必要元信息；每文件有独立受理／上传状态与期限。
3. 在 IA-04 看生效版／候选／任务三区；首次导入无生效版时暂不可查。进入 IA-06 对照原件、提取结构、可靠位置和失败范围。
4. 普通完整文档程序校核通过自动发布；首次部分可用只显示可靠可用范围，持续提示不完整。要修正时重新上传修订原件或合法参数形成新候选，不改历史来源。
5. 资料更新时阿宁发起替换，看旧版仍可查询；候选不完整保留待处理，完整就绪且仍为当前候选后才切换。
6. **高潮：** 阿宁能同时确认“用户现在查的是哪个版本”“新候选哪里失败”“引用能回到哪里”，完成替换后新问答使用新版，旧引用仍按旧版核验。
7. 删除时先确认影响，系统停止资料访问，再展示清理中／失败／完成；阿宁可按权限重试清理，看到容量只有实际清完才释放。

失败分支：坏文件／超限／容量不足→逐文件明确拒绝；半传断网→查原上传，不重置期限；过期／放弃→保留终态，显式新上传才新受理；云端未知→有限查原任务，阈值后需处理。到期后继续核对是只读核对，真正继续处理是新本地操作，重新提交解析则告知重复费用后显式发起。被降级但仍可读者仅看本人状态；离队／撤库权不能读改，但合法受理库任务不因此自动取消。见 [FR-6–8](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:193)，范围：193–223；[FR-15](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:283)，范围：283–293。

### Flow 6 — 邀请、库授权、责任交接与转让（团队所有者阿敏）

1. 阿敏在 IA-11 选择已有有效账号，发带目标角色的站内邀请；IA-02 中目标账号接受后才成为成员。
2. 阿敏查看成员角色与逐库授权，明确新成员入队尚未自动获得库权限；为需要的库授权。
3. 对负责库的维护者降级／移除／撤库访问时，确认职责由所有者接管、资料保留及当前失权影响；提交后以服务端新状态更新。
4. **高潮：** 阿敏可核对成员“能做什么”和“能访问哪些库”，并看到负责职责已接管；旧负责人不能借创建者身份自行恢复库访问。
5. 需要退出所有者身份时，先向有效团队成员转让。旧所有者转维护者，仅保留原逐库／负责库范围，不自动获得此前未有的逐库授权；如需解散团队，明确停止全部访问并进入关联清理。

失败分支：未接受／撤销邀请不能入队；无合资格接任者不执行退出／停用；管理回包丢失先读取当前成员／授权状态，不重复宣称或重新发动作；平台身份不因办理所有者变更获得业务读权。见 [FR-2–3](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:133)，范围：133–153。

### Flow 7 — 登录、切空间与安全历史回看（新员工小周）

1. 小周在 IA-01 登录，应用框架先确认本人、当前可用空间与身份，不恢复旧账号正文。
2. 进入 IA-02 选择团队，进入 IA-03 看授权库；暂无授权时只显示当前范围的空态。
3. 从 IA-07 打开同空间历史，每次重新鉴权；从历史引用进入 IA-09 回看原版本。
4. 小周切到个人空间：先提示新空间需新会话，清旧空间私有视图，再取当前上下文；后台迟到结果仍归原操作，不落入个人空间。
5. **高潮：** 小周能清楚判断自己目前在哪个空间，历史引用属于哪个版本；切换后不会误把团队答案当成个人资料。
6. 本人账户可改密码或退出；退出清理私有视图，不把 Abort 当作已经取消后台业务。

失败分支：历史所依赖库被撤权／删除→受影响回答整体隐藏并给安全说明；后台标签页恢复先重核context，不自动加载旧正文；纪元改变使旧会话／凭证失效时按当前身份处理，不自动新凭证或重交旧问题。见 [FR-14](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:269)，范围：269–279；[前端恢复](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/implementation-contract.md:395)，范围：395–401。

### Flow 8 — 本人只读凭证与用量核对（程序凭证持有人阿禾，支持流程走查人物）

1. 阿禾从 IA-10 创建本人程序凭证，明确单一空间、指定库、只读动作和到期；有效范围仍取持有人当前权限交集。
2. 创建成功仅此时显示密钥；阿禾显式复制并自行保存，之后只见元信息和撤销动作。
3. 在用量面板区分原件容量、上海日期的问答计次，以及真实外部调用和可取得费用，不把配额余额当剩余费用。
4. **高潮：** 阿禾能说明凭证可查哪些资料、哪些动作做不了，并核对正常澄清计一次、原成功结果恢复不再扣一次、失败外部调用仍可能有成本。
5. 不再使用时撤销本人凭证；团队所有者仅在本团队范围办理撤销，不扩展程序写权限。

失败分支：创建结果丢失→读取元信息，不自动再造密钥；明文没拿到时可明确撤销并重建；退出团队／撤库权／停用／过期后凭证失效或缩窄；Cookie＋Bearer双渠道请求整拒，不回退另一身份；未知费用显示待核对。见 [FR-4–5](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:165)，范围：165–189。

### Flow 9 — 接入、索引与可信运行状态（平台管理员阿岚）

1. 阿岚进入 IA-12 的独立平台管理，创建账号／团队并指定初始所有者；不出现全局业务正文搜索或代登录入口。
2. 配置模型／存储／配额，执行当前合法接入验证；失败显示明确原因和状态，未验证不标已可用。
3. 阿岚更新默认配置，已有库保持原 profile 并提示需显式重建或维护迁移；具体库重建只由当前具备该库维护权限的操作者显式发起。阿岚仅凭平台身份查看受控运行元数据与影响说明；兼有业务身份时才按该身份的当前库权限操作。同维重建旧索引继续读，写入被服务端guard拒绝；维度变化不假称在线切换。
4. 查看任务／依赖运行、必要审计和用量元数据，区分已验证、未知、失败及存储保护；不由运维身份读取业务资料。
5. **高潮：** 阿岚能判断某范围是否真实可用、写入为何受限、账是否待核对；在恢复后逐范围核验开放，不把系统启动或备份存在当全部恢复成功。

失败分支：恢复默认隔离，旧身份／会话／凭证失效；只有已独立核验并有范围权者可见隔离／配额核对细节，未知范围继续拒绝。重建失败／取消／过期须依服务端释放本guard，旧任务不能解除新guard；清理失败与磁盘保护不能用降低权限／忽略成本解除。见 [FR-4](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md:157)，范围：157–173；[可信恢复](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/implementation-contract.md:276)，范围：276–300。
