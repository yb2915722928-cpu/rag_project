# RAG_all 纵向实施切片与前置门槛

目的：使开发者可按已记录行为逐步实现和验收，不把“需求定稿”误当“所有能力已验证”。范围与唯一验收基线是 [PRD](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/prd.md)，跨模块政策见 [实施契约](/E:/aaa-project/rag/_bmad-output/planning-artifacts/prds/prd-RAG_all-2026-10-15/ir-review-2026-10-15/implementation-contract.md)。这是可拆成故事的实施单元，不是已运行冲刺或已完成代码；不生成虚构 sprint-status。

两位 John 最终 IR 已确认可按本文件开始，剩余 material 规划问题 0。P0 和每个切片的账号／环境／真实能力验证条件仍须执行，不能将此状态当作这些条件已通过。

## 先后关系

S0 → S1 → S2 → S3 → S4 → S5 → S6 → S7。外部能力探路 P0 在 S0 的适配器和记录骨架可用、真实凭证具备后尽早开展，可与 S1 并行；不等全部业务页面做完才第一次测格式、图意或资源。

每个切片可以依赖已完成的基础能力，但不能依赖未来尚未决定的业务行为。半个月是用户预期，未分配虚假工时或固定完成日期；实际推进记录方案就绪、AI 额度和真实阻碍。

## S0：可重建的工程基础和隔离适配器

- **前置：** 已记录的 PRD 与实施契约；无需外部模型账号即可开始。
- **交付：** 模块化应用／worker 骨架、配置与秘密注入、依赖／镜像锁定、真实 PG＋pgvector 的迁移、短 Session、统一错误与 request_id／operation_id 结构；MinerU、embedding、问答和可选图意适配器的输入输出及可控假件。
- **验收：** 干净环境可启动／迁移／停止；配置缺失可识别；假件能明确模拟成功、超时、未知与非法结果，不能被标成真实服务通过；日志无凭据或私有正文。
- **出处：** NFR-3／5／6、FR-4／15／16；本阶段不宣称 SM-1–SM-7 全通过。
- **失败处理：** 迁移或配置失败先定位修复，不跳过为 SQLite 的通过结果来替代 PG 事务与向量行为。

## P0：真实外部能力与目标资源探路

- **前置：** S0 适配器／调用记录；可用账号与合法样例。实际调用前取得运行侧凭据，按已确认的 API 方向执行，不把开发工具账号当运行服务。
- **交付：** 固定原件版本与 hash 的 PDF／DOCX／TXT／MD 样例，规则及简单跨页表格、扫描页、必须理解图中连接关系的题；实际 MinerU 响应／ZIP、来源映射、embedding 配置／维度与问答结构，必要时独立视觉 API 的实际结果。
- **验收：** 文本、表头行列、数值单位、页／结构引用可回查；图意题必须有直接依据，图注或仅识字不算通过。实际调用状态、用量／费用或未知及失败记录完整。目标 4C4GB 主机接通后测服务并存 RSS、连接、磁盘、超时；开发电脑结果不替代生产资源结果。
- **缺口分支：** MinerU 图意不足仅触发图意 API 验证，保留 MinerU 主路和绑定来源；定位不足先修适配／回退，不猜位置。仍达不到 FR-7 则阻断 S5／整期完成，不能降验收或假称图意已支持。资源不足先限制并发、流式与输入上限再测；仍不能满足记录真实变更提案。
- **边界：** 账号／环境暂缺时可继续 S0／S1 的独立工作，不能以假件成绩替代 P0；S2 的真实格式接通须通过对应解析与来源检查，S5 须通过图意分支。

## S1：身份、空间、知识库与受控准入

- **前置：** S0；无需真实模型调用。
- **交付：** 初始化平台账号、密码登录／退出／改密、个人与团队、所有者／维护者／使用者及逐库授权、用户只读凭证、统一认证／授权、请求与容量账本。
- **验收：** FR-1–FR-5 的角色／转让／撤权反例；双凭据、混合越界目标整体拒绝；无权与不存在目标不泄露存在性。并发争最后一笔原件／次数预留仅一笔成功；无效同键、异内容、过期和崩溃回收按契约。
- **出处：** FR-1–FR-5、NFR-1／2／6、SM-6 的对应基础用例。
- **失败处理：** 任一越权或重复计账未修复不能进入外部调用；不靠隐藏按钮通过。

## S2：文档导入、替换、删除与恢复闭环

- **前置：** S1；P0 对应格式、MinerU 上传／查询／来源检查通过。
- **交付：** 逐文件预留与候选上传、原件／产物受控存储、PG 持久任务、单文档处理与独立续租、上游 ID／阶段产物、正常／部分可用／待核对、完整候选切换、墓碑与清理。
- **验收：** 五类承诺格式可按配置处理；首次部分可用明确范围、不完整替换不盖旧版；上传重传不新增版本；旧 worker、乱序替换、删除竞态、清理失败、上游未知与重启均不复活／重复生效／丢失占用账。
- **出处：** FR-6–FR-8／15、NFR-1／2／6、SM-5／6／7 的导入生命周期部分。
- **失败处理：** 按原任务核对，不自动盲重交；缺必要来源不发布；任何旧版破坏或删除后可读均阻断本切片。

## S3：企业查询的基线 RAG、引用、历史与只读 API

- **前置：** S2；P0 的实际 embedding／问答能力接通。
- **交付：** 结构化分块、独立 embedding profile 与同维存储，授权精确向量 B0，全请求最终五块，企业查询 schema、引用 resolve、同空间追问与历史、程序只读接口；持久逻辑操作、原输入／执行快照与结果重放。
- **验收：** SC-2 开发题有可核查答案；无候选为受控不足，依赖失败不冒充不足；非法 schema／ID 整答失败；撤权或来源删除后不能重放旧答；成功提交后丢回包不重复调用／扣次。同一会话并发和轮次按实施契约处理。
- **出处：** FR-5／9／11／14／16、NFR-1／3／4、SM-1–SM-4 对应开发检查；不将开发题成绩充作冻结验收。
- **失败处理：** 保留 B0、具体失败与真实费用；不先加关键词／重排／ANN 掩盖未闭合的证据链。

## S4：排障与多文档对比

- **前置：** S3。
- **交付：** 环境／版本／日志输入、候选原因与检查顺序；comparison.v1 的对象／条件受理、固定名次轮转、逐格四态、完整矩阵与证据目录；Web／程序语义一致。
- **验收：** SC-1 不执行命令、不把候选原因说成已确定；SC-3 受理上限／重复／越权整体拒绝，缺格和引用越界失败；满足／明确不满足／冲突具备规定证据，未找到不是不支持。零候选全格保留且正常计次，复杂任务不扩大 K 或偷加全文。
- **出处：** FR-9／10／12／14、NFR-1／4、SM-1–SM-5 对应开发题与 SM-6。
- **失败处理：** 如实报具体格不足并保留原完成门槛，不为刷分改金标分母或全面拒答。

## S5：复杂手册与可校核来源

- **前置：** S4、P0 的结构／扫描／真正图意检查通过；必要的图意适配器按缺口分支接入。
- **交付：** 型号／版本／参数约束、规则与简单跨页表格、OCR、带原图／位置的图意说明；校核对照页和 PDF／非 PDF 最小回看。
- **验收：** 表头、行列、数值／单位人工对照一致，图中连接问题有直接依据；无 bbox 回退页预览，非 PDF 不编物理页；定位损坏明确失败。修正新候选不原地改历史，普通正常文档不逐份审批。
- **出处：** FR-7／9／13／14、SM-1／2／3／5／6，SC-4 不由纯文本题替代。
- **失败处理：** 不能有依据完成则保持失败／阻断整期，不以平均分或已有其他场景通过宣布完成。

## S6：索引变更、目标部署与可信恢复

- **前置：** S5；真实目标环境访问、匹配备份材料与恢复操作者条件具备。
- **交付：** 逐库索引代与 guard、同维重建／异维维护迁移边界、四服务部署与有效限额、独立安全变更依据和隔离恢复流程。
- **验收：** 重建并发上传／删除、过期 guard 与旧 attempt 不锁死／不切错；profile 不兼容整拒；干净启动与备份后撤权／删除再恢复演练、旧凭据作废、未确认资源拒绝、未完任务与账本核对均通过。没有实际账号／证书不得声称已上线。
- **出处：** FR-3／4／8／15／16、NFR-1–NFR-6、SM-6／7。
- **失败处理：** 不因恢复能打开旧引用就放行；未知安全事实保持隔离。异维迁移失败保留可恢复旧存储，不自动改 DDL 或混查。

## S7：固定验收、优化比较与工程证据

- **前置：** S6；四场景开发检查完成，环境／资料／模型／分块／检索与合并配置已固定。
- **交付：** 题目／金标来源／必要证据单元／口径冻结；开发题上提出优化并锁方案；相同冻结题与条件下保留 B0、上一保留轮和本轮的完整原始输出、权限／故障／恢复结果、资源和实际费用。补 API／部署文档、一次真实异常复盘和用户理解材料。
- **验收：** SM-1–SM-7 全部按 PRD 判断；权限独立全通过，关键表格／OCR／图意／冲突／版本题不能由其他得分抵消。首次资源／成本基线后、优化比较前登记绝对目标，少量样本不包装泛化或捏造 P95。
- **防泄漏：** 调优只据开发题，不用冻结题逐题反馈选参数；冻结配置、原始题目和全部结果留档。若题目暴露，记录污染并另备留出验证，不删失败／改分母。优化无收益／退步仍保留，不预填提升百分比。
- **出处：** FR-1–FR-16、NFR-1–NFR-6、SM-1–SM-7、PRD 第 8.2–8.4 节。
- **失败处理：** 未达标报告差距并继续修复或按真实证据提出变更，不以切片已完成替代整期完成；AI 做过与用户能解释的范围分别记录。

## 开始与完成的不同门槛

IR 的“可开始实施”只要求上述政策、前后依赖、受理／状态／结果和验证路径已经明确。实际 P0、部署、数据质量或资源尚未运行，不是可省略的检查；它们是明确的执行停止点。S0 可在当前记录基础上独立启动，后续切片须满足所列前置条件，最终完成必须全部验收通过。
