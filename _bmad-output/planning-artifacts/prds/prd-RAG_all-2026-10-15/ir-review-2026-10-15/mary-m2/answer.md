**TS① 索引。** 每库持有不可变 embedding_profile，记录供应商／端点地域、模型及可观察版本、维度、query/document 处理与前缀、L2 归一化及余弦策略；仅轮换凭据不算换向量空间。active_index_generation 指向已完整发布的索引代，其身份／配置／初始快照不变，正常文档增量发布另递增 docset_revision，不要求逐份全库重建。平台改默认配置不原地改变旧库；多库兼容指纹不同仍整请求拒绝，不只凭模型名判断。

同维重建开始前，若有未终结的资料写任务，拒绝重建；否则锁库取得有租约／attempt 的写 guard，固定 docset_revision 与 active 文档版本集。旧索引继续读，上传／替换／重处理整拒，不暗排队。删除仍允许，先 tombstone，再递增 revision、使候选失效并释放所属 guard；失败、取消、租约过期也必须由恢复器条件释放。所有解锁匹配库、所属任务、代次与令牌，旧 attempt 不能释放新 guard，更不能续活或切换。切前在同库锁下复核当前 attempt、租约、完整性、revision 和覆盖版本未变，才原子改指针并解锁；不同库逐库切换。请求执行及重放保留 M1 原快照并重新授权。索引重建只覆盖已发布合格块，不把首次部分可用文档改标完整，也不暗中发布文档候选。

首版维度 D 由首个实际接入并验证的配置锁定；改成 D2 的在线请求直接提示需维护迁移。用维护窗口、备份、显式 Alembic 创建隔离的 D2 存储，按完整迁移流程重建并验证所有受影响库、授权及失败退回，保留旧存储可退回，应用不自动 DDL，不承诺任意维度在线双索引。这样避免全平台双写及任意维度管理；代价是重建时库内不能新增资料，变维需要停服维护、候选暂占额外空间。未来确有连续写需求再论证增量追平。

**TS② 对比。** 可配置初值选文档 2–4、条件 1–6、每条 256 Unicode 码点、总条件文本 1024 码点、子查询至多 24；均未测。重复对象／条件、空条件或越限整拒，不静默删减。稳定 object_id／condition_id 绑定本次文档版本，恰好返回全部格。满足、明确不满足各至少一条直接证据；冲突至少两条不同证据并列双方；不足允许空证据但必须说明缺口，不能把没搜到写成不支持。schema 示例与逐态校验已单列，前后端共用。

检索仍按条件原序、文档 ID 顺序按名次轮转去重，最终全请求最多五块，不跨 query 比分；所有格只能引用这五块的白名单。零候选由后端确定性返回全格结构化不足，属于正常结果，按 M1 计一次；纯检索零结果不扣产品次数，真实 embedding 成本照记。模型缺格、非法引用或结构错误仍整答 ANSWER_VALIDATION_FAILED，不追加 LLM 修复，也不伪装不足成功。代价是受理上限与五块可能限制覆盖；据实不足并保留失败，不能更换金标分母或降低场景门槛。

**TS③ 校核与回看。** 页面分列生效版、候选及任务；普通资料程序通过即自动发布。维护者能对照原件、提取／结构差异及失败范围，重试、继续查询未知任务，或知情显式重交。首版修正限修订原件重传、合法元信息／解析参数产生新候选，不做通用 OCR／富文本编辑器，不原地改历史来源。PDF 有可靠 bbox 则页内高亮，无 bbox 则页预览及位置提示；DOCX／TXT／MD 提供结构路径、准确提取片段和受控原件下载，明确片段与原件区别，不加 Word 服务。所有出口重新授权，定位失败明确显示，不能猜页或造坐标。代价是纠错需重处理，编辑能力较窄。

**TS④ 前置探路。** MinerU 结构解析不等于任意图意。已选公开 TI LM2596 手册首页连接图作预探样本：运行前冻结必须读连线的事实、原件哈希和定位，再检验 MinerU 产物。若不足只触发独立视觉 API 验证，不换 MinerU、不默认本地 OCR；仍无依据则阻断 SC-4 完成。并先验证 PDF／非 PDF 回看与 4C4GB 的实际峰值、磁盘、延时及调用账。账号与视觉型号接入时选；样例执行、实际质量与费用均未运行。

后续须用五类失败验收收口：

1. 重建中删文档、任务过期后迟到返回：候选不可切换，guard 释放，旧合法索引可查，墓碑内容不可访问。
2. A 已换 profile、B 未换：单库按各自版本可用，A+B 整拒；异维在线变更也整拒。
3. 重复／越限输入无 embedding 执行；零候选全格合法不足并只计一次，非法引用／缺格整答失败并释放预留。
4. 替换候选部分失败不盖旧版；DOCX 无页、PDF 无 bbox 与定位损坏分别走真实回退，撤权／删除后旧引用受阻。
5. 图注存在但连线事实答错仍失败；独立视觉验证也失败时不得宣布 SC-4 完成或以平均分掩盖。
