## TS：选择与代价

1. **页面自建。** Vue Router＋Pinia＋Element Plus：登录／空间切换、库与文档管理、任务详情、查询与对比、引用、历史、只读 API 密钥、连接设置及审计用量。表单复用组件，业务交互自写；代价是需要独立联调。两项目 LICENSE 分别为 MIT（另列第三方）和 GPLv3 文本，不据此作法律定论或整页复制。
2. **状态由服务端作准。** Pinia 只保身份、当前空间和界面状态；切空间／退出清理私有缓存。任务定时轮询，答案一次完整返回；引用用后端返回的 ID 解析，Markdown 清洗后渲染。多等一次完整答复，换取与既定放行检查一致。
3. **电脑构建、同源发布。** 锁依赖，类型检查后生成静态产物；服务器不用 Node 构建。Nginx 提供页面、API 代理和 HTTPS，证书私钥只读挂载；域名／证书接入时确认，未就绪先用本地或隧道验收。代价是要维护证书续期和前后端版本配对。
4. **四服务 Compose。** API 单进程、独立 worker、PG＋pgvector、gateway；只开放 gateway，服务内网通信。迁移单独执行，镜像／配置／迁移版本随发布记录；健康检查、重启和故障恢复要实测。数据迁移须评估回退，不能把换回镜像当数据库回滚。
5. **文件受控保存。** 原件、MinerU 原响应／ZIP、校验后产物按内部文档 ID／版本分目录，PG 存关系、哈希、来源及有效状态。流式落盘、临时写后原子提交；浏览／下载实时授权、禁止静态直链。多一次后端传输，减少路径泄漏和越权入口。
6. **先做停写恢复。** 维护状态拒绝新业务，等在途结束，停 API／worker；同一备份号保存 DB、文件、必要角色授权、配置和版本清单。供应方密文随 DB 备，主密钥另行加密封存；保留离机加密副本。恢复演练确认关联、哈希、授权与续跑后才算可用；代价是维护窗口。
7. **区分两类密钥。** 用户程序 key 仍只存 hash；千问／MinerU 服务密钥需调用可恢复，选择服务端认证加密，外置主密钥经容器 secret 注入，记录 key_id 便于轮换。界面不回显、不进前端构建、日志脱敏；宿主 secret 文件仍要权限保护。
8. **记录分工。** JSON 运行日志串起 request/task/stage、状态、耗时和错误码；PG 审计记权限／配置／删除／下载，调用账记模型、配置、请求状态、usage 和失败成本。usage 未知存 unknown，估价标估价，账单另核；不默认记录私有全文。轮转日志，证据另行受控保存，代价是需要清理与对账。
9. **先限流再测量。** 用下表起步，队列有界、超量明确拒绝；上游真实限额接入时核对。UTC 存时间、上海时区展示及每日配额边界；超时／未知状态按原任务核查，不盲重投。初值不能写成容量承诺。
10. **按风险验证。** pytest 测规则／条件提交，真实 PG 测事务与恢复，独立安全套件测跨空间、撤权与私有文件，Playwright 跑主要页面。AI 先整理每场景3份、共12份公开或明确模拟资料，覆盖复杂格式；实施统计页数／字数／块数。32冻结题保留独立验收；首基线后才登记绝对性能与成本门槛。

## 白话复述

电脑负责把页面做好，服务器只把页面发出去并处理业务。原件和解析证据锁在后台，点引用也重新查权限。先用较低并发跑四类资料，保存失败、耗时和真实费用；备份必须在干净环境恢复成功，才能叫可恢复。4GB 是否够用，由这套测量决定。

## 四项验证

1. 页面主流程＋32题：四场景、引用、状态和失败提示可追溯。
2. 安全：撤权、过期 key、历史／下载、CSRF、路径穿越和渲染注入独立测试。
3. 恢复：中断 worker、未知上游任务、磁盘不足及全量备份恢复，旧任务不得复活删除内容。
